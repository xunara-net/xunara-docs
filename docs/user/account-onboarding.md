# 设备名称与账户入门

## MagicDNS

在「DNS」点击「启用 MagicDNS」，确认系统给本网络分配的独立内部域名。网络管理员
才能启用，免费套餐也能用；设备 IP 和密钥不改变。客户端须接受网络 DNS。
随后可用设备短名称或完整名称访问，不必手记 IP。「设备名称」显示实际分配的名称。

首次域名保持稳定，不直接更名；需要暂停名称解析时关闭 MagicDNS 开关，之后可再次
开启。高级解析器、搜索域、分流及自定义记录按实际套餐权限开放。内部解析不是公网
DNS 或自动公网 HTTPS 证书。

## 第三方绑定

在「安全中心 → 第三方账号绑定」选择已配置的登录提供方并授权。回到同一账户后
可用该来源登录，绑定不会创建重复成员、按邮箱合并或自动批准组网设备。

退出、切换账户或撤销发起会话会中止绑定。解绑须保留另一种本部署可用的登录方式，
否则页面显示拒绝原因。该提供方来源的控制台登录会退出，设备连接不受影响。
没有提供方配置时页面明确提示管理员配置，不用测试发行方冒充生产账号。

## 邀请加入

所有者在「成员」选择角色和有效期创建邀请码。注册码一次展示，把注册页面地址和
代码分开发送。受邀人输入代码后可设置密码加入，也可使用网络已配置的 OIDC。
兑换时仍校验实际成员额度、过期、撤销和单次使用；授权期间撤销的邀请不能继续注册。

已有绑定可正常登录，但普通 OIDC 登录不能绕过 invite/closed 准入，也不能用邀请码
改变既有账户角色。独立网络开通入口不是共享成员入口。

## 部署与边界

必须先升级服务端再部署 Web，迁移与配置以
[服务端操作说明](https://github.com/xunara-net/xunara-server/blob/main/docs/account-onboarding-and-magicdns.md)
为准；架构决定见
[ADR-0027](https://github.com/xunara-net/xunara-server/blob/main/docs/adr/ADR-0027-account-onboarding-and-magicdns.md)。

本次追加 identity v14，保留已有身份、会话、邀请、设备和套餐；未初始化网络不会
升级后自动启用 MagicDNS。未知第三方首次登录必须符合部署准入，这是有意的安全变化。
回退需要完整旧状态，不能让旧二进制直接读新库。

尚未交付邮箱邀请自动发送、全局账户跨租户加入、邮箱验证/找回、2FA、域名迁移，
也未宣称所有客户端操作系统 DNS 接管均完成验收。公网 OIDC 需要管理员提供实际
issuer/client ID、在服务器安全保存 client secret，并验证固定 HTTPS 回调。
