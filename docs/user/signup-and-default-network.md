# 开户名称与默认网段

## 注册

公开开户入口的用户名不区分大小写，前后空格不产生新账号。同名注册会提示
「该用户名已注册」，请直接登录或换一个名字，不会再次创建网络。
网络标识和密码仍属于你的独立网络；不会仅凭邮箱把其他用户合并进来。

如果旧版已经创建过多个同名账户，它们暂时都保留。请确认实际使用的网络标识，
再由管理员协助整理；不要删除不确定是否已有设备、密钥或资料的网络。
出现「注册结果未确认」时先登录核对，避免连点注册导致重复开通。

## 默认网段

网络所有者或管理员打开「我的网络」，点击「修改分配网段」设置默认 IPv4 CIDR。
已经添加的附加网段旁有「设为默认网段」。切换时旧默认网段保留为附加网段，
先看预览，再确认保存；取消不会修改网络。

新设备从默认网段分配 IP，已加入设备的 IP 保持不变。需要移动已有设备时，在
设备详情中逐台修改，并检查 ACL、应用和外部 DNS；多网段不等同于 VLAN 隔离。
保留地址、本地冲突风险、其他租户占用检查仍然必要，不能配置任意危险地址。

是否开放由后台套餐中的自定义网段开关决定，运营者可以为 Free 开启而不调整
10 台设备额度；用户页面依据服务器实际权限，不按套餐名字硬编码放行。

## 边界

名称修复和网段选择不会修好旧 nip.io 原生客户端地址的 DNS / 证书。
网页能打开，不代表那条 Tailscale 接入命令可用；不要把主域名直接换进去而让
设备加入默认网络。此问题仍需独立客户端路由及正式证书方案。

接口、数据库版本、失败恢复与兼容性以
[服务端说明](https://github.com/xunara-net/xunara-server/blob/main/docs/signup-network-settings.md)
和 [ADR-0043](https://github.com/xunara-net/xunara-server/blob/main/docs/adr/ADR-0043-public-signup-uniqueness-and-default-network.md)为准。
