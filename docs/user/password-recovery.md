# 忘记密码

不需要重置码。当前使用平台人工恢复，不是自动邮件找回。

1. 联系平台管理员，提供所属网络 ID 和登录名，通过可靠独立渠道核实身份。
2. 管理员直接将密码重置为随机临时密码，告知你所属网络的正常登录地址。
3. 输入登录名和临时密码登录，进入「设置自己的新密码」。
4. 输入临时密码、新密码和确认密码；成功后以自己的新密码重新登录。

临时密码不能长期使用，完成本人改密前不能使用控制台功能。
管理员不能读取你的旧密码，最终密码由你自行设置，不要把它交给管理员。
新密码至少 12 个字符、最多 72 字节，不能等于登录名或临时密码；中文和表情占多个字节。

## 注意

- 旧重置码和兑换表单已停用；「忘记密码」只提供联系管理员的指导。
- 必须在所属网络的可信 HTTPS 登录页操作，不把密码加到网址、工单或截图。
- 管理员重置和本人改密都会退出该账号所有控制台登录，其他账号 / 网络不受影响。
- 组网设备、中继、API Key、设备接入 Key、第三方及 Passkey 绑定不删除；
  重置后这些人类登录方式也要先完成本人改密，独立服务凭据不受影响。
- 重置不能绕过禁用；没有本地密码的第三方专用账号仍使用原登录方式。
- 提交超时 / 失败不会自动重试。无法确认时先退出，尝试新密码登录，再请管理员核对；
  不要假设超时等于没有改密。

联系邮箱未经验证，不能独自充当身份证明。疑似账号被接管需进一步检查绑定、
密钥和设备；单独重置密码不是全面接管恢复。邮箱验证、自动邮件找回和完整 2FA 尚未交付。

管理员操作见[平台手册](../admin/password-recovery.md)，兼容 / 升级边界以
[服务端手册](https://github.com/xunara-net/xunara-server/blob/main/docs/password-recovery.md)与
[ADR-0042](https://github.com/xunara-net/xunara-server/blob/main/docs/adr/ADR-0042-platform-random-password-reset.md)为准。
