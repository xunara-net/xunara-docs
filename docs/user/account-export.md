# 导出自己的账户安全资料

这是当前网络中本人的私人文件，不是整个平台、全部个人数据或网络备份。
平台管理员也不能通过平台令牌代读你的私人导出。

## 操作

1. 使用自己的账号登录，在侧栏进入「个人设置」。
2. 展开「个人数据导出」。选择「账户安全资料（JSON）」或「成功登录记录（CSV）」。
3. 按需选择登录记录的开始 / 结束日期；结束当天包含在内，采用浏览器时区。
   资料、绑定和活动会话不受日期筛选。留空导出当前保留的全部成功记录。
4. 确认知晓文件含私人资料，再点击「确认并下载」。
5. 在浏览器下载列表确认文件，保存到私人位置，不上传公开仓库或发送给无关人员。

JSON 包含已保存的资料、绑定展示属性、通行密钥名称 / 时间、活动登录和成功
记录。CSV 仅为登录记录表格，时间是 UTC。没有密码、令牌 / 哈希、CSRF、
外部 subject / token、通行密钥认证材料、其他成员资料或设备私钥。
未保存的设置草稿不包含在内；联系邮箱仍未验证，不成为账号合并 / 找回依据。

## 失败、取消与边界

- 每集合最多 5000 条，文件最大 8 MiB。超限明确拒绝，不静默截断。缩小历史
  区间重试；其他集合仍超限时联系管理员，不必为了导出而删除重要绑定。
- 准备时可以取消，离页也会取消；不会自动重试。取消或失败可能已消耗请求
  次数，限流时稍后再试。服务器审计的是准备快照，不证明你已保存文件。
- 服务不可用、响应不完整或版本不兼容不生成下载文件，不表示没有资料；
  旧服务端会提示升级。文件由浏览器临时接收，页面不持久存储私人内容。
- 旧记录未记录的 IP / 客户端仍未知，轮换不是新认证；已清理且不再保留的旧
  事实不能恢复。活动时间不是设备实时在线或可信硬件证明。
- CSV 中可能作为公式的文本加「文本：」前缀，方便安全查看，原值请查看 JSON。
  不建议自行删除前缀后用表格打开，不保证任意表格软件 / 再保存后的行为。
- 这不是凭据备份，不能用来恢复登录、机器身份或网络配置。设备 / 网络 /
  ACL / DNS / 路由导出、自动保留清理、完整注销仍是后续工作。

接口、具体限额、时间 / 白名单、事务与升级边界以
[服务端说明](https://github.com/xunara-net/xunara-server/blob/main/docs/account-security-export.md)
和 [ADR-0033](https://github.com/xunara-net/xunara-server/blob/main/docs/adr/ADR-0033-account-security-export.md)
为准；不要将可下载文件视为完整运维备份。
