# 查看登录记录

进入用户中心侧栏 **安全中心**。活动登录在最上方：浏览器 / 系统线索、来源 IP、
登录时间、最近活动和到期时间；手机上以卡片展示，不需要左右拖动表格找退出按钮。
退出单个、其他、全部的确认和权限保持；只影响控制台登录，不断开组网设备。

展开 **登录记录** 查看本人成功登录历史，使用上一页 / 下一页或刷新最新记录。
记录独立于可过期清理的会话：已退出或过期也可查看，无需重复撤销。
失败会明确报错；已有数据只代表上次成功读取，可显式重试，不会假装没有历史。
旧后端不支持时提示联系管理员升级，活动登录仍可管理。

## 如何理解记录

- **当前浏览器**：本次控制台登录，不是当前组网设备。
- **最近活动**：有效会话使用时按分钟更新，不是持续在线或滑动延长有效期。
- **浏览器 / 系统**：客户端自报的线索，可能被伪造，不是可信硬件认证。
- **来源 IP**：首次认证连接地址，经过受信代理时按部署规则采集，不代表城市。
- **旧记录**：升级时保留的原会话事实，未采集的来源不补猜；更早被清理的历史
  无法恢复。缺少来源或活动时明示“未记录”。
- **会话轮换**：继承原登录来源，不代表该时间又完成一次认证。
- **密码重置 / 改密 / 账号禁用 / 解绑**：相关退出原因按服务端实际事实展示。

页面不包含失败登录尝试、地理位置或组网设备在线轨迹；发现可疑登录，先退出
相关会话、修改密码并核查第三方 / 通行密钥和独立服务密钥，不只靠一行浏览器名称
判断安全。记录目前随账号保留，删除账号时移除其会话与历史；自动限期保留 /
导出仍未交付，备份的保留由平台运营者负责。

接口、权限和升级以
[服务端手册](https://github.com/xunara-net/xunara-server/blob/main/docs/account-login-history.md)为准；
2FA、邮箱验证、自动邮件找回和完整账号生命周期仍是其他待开发能力。
