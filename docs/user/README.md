# 用户手册

面向 Tailnet 使用者（普通账号）。控制台与 API 同源部署，登录后所有操作都在
`/dashboard` 及其子页面完成。

## 入口

```text
/login       登录（密码 / Passkey / 身份提供方）
/register    注册（按部署配置：邀请码、开放注册或自动开通独立网络）
/setup       首次初始化管理员（仅全新部署，使用一次性令牌）
```

## 导航（规范 §8、§93）

| 页面 | 路径 | 内容 |
|---|---|---|
| 概览 | `/dashboard` | 设备在线数、网络状态、套餐余量、安全提示 |
| 我的设备 | `/devices` | 列表、状态、审批、改名、路由、删除；`/devices/:id` 详情 |
| 网络中心 | `/network` | 网段、DNS、DERP、连接方式（直连/中继） |
| 拓扑 | `/topology` | 设备布局视图；尚非实时连接路径遥测 |
| 权限 | `/permissions` | 规则/权限底座说明；完整可视化编辑尚未交付 |
| 成员 | `/members` | 组织成员与角色 |
| DNS | `/dns` | DNS 信息读取与记录删除；新增/编辑尚未交付 |
| 路由 | `/routes` | Subnet Router / Exit Node 审批与状态 |
| API | `/api` | API Key 与预认证密钥 |
| 安全 | `/security` | 控制台会话管理、安全概览与修改密码入口 |
| 套餐 | `/plan` | 当前套餐、用量与能力；尚未接支付升级 |
| 审计 | `/audit` | 关键操作记录 |
| 设置 | `/settings` | 昵称、联系邮箱与本地密码管理 |

## 常见任务

- **加入设备**：`tailscale up --login-server https://<控制面地址>`，然后在「我的设备」
  批准；或创建预认证密钥（一次性凭据只显示一次）。
- **连接不上**：先在「网络中心」看是否有可用 DERP；没有中继时客户端会停在
  `Starting`。详见 [排障](../troubleshooting/README.md)。
- **权限**：七种可视化方式、影响预览与策略模拟是规格目标，当前仍需开发；不要把布局连线视作已下发授权。
- **套餐限制**：Free 默认 10 台设备、网段不可改；达到上限时升级套餐（错误码
  `DEVICE_LIMIT_REACHED`）。

## 账号安全

在「个人设置」修改昵称和联系邮箱，保存后控制台会同步展示新资料。登录名、
角色和网络所属组织不能通过个人设置修改。联系邮箱可清空，尚未验证，不会
成为登录凭据或自动关联第三方身份。

「安全中心」可以退出单个、其他或全部控制台登录，并通过「修改密码」进入个人设置。
“退出其他登录”保留当前浏览器；“退出全部登录”也会退出当前浏览器并返回登录页。
操作需确认，成功后显示实际退出数量；失败不会显示为退出成功。普通成员和
免费账户也可以管理自己的登录，不能操作其他用户或租户。

活动登录与已失效记录分开显示；失效记录无需再撤销，只展示服务端仍保留的
会话，不代表完整登录历史。当前尚未采集浏览器型号、来源位置或最后活动时间。
网络安全概览以中文卡片和提示展示审批、密钥、访问规则和中继配置；
没有提示不等于完整安全审计，中继配置也不代表实时健康状态。

「通行密钥」可绑定用于指纹、面容、设备 PIN 或安全密钥验证的登录凭据，
设置名称、查看添加/使用时间或删除；管理员启用当前租户的 WebAuthn 且站点
通过固定 HTTPS 域名访问时，登录页提供相应入口。HTTP 公网调试环境无法使用，
界面说明不可用原因。通行密钥只登录本账户，不批准组网设备。
删除前务必保留密码、其他密钥或可用的第三方登录，删除不会自动退出已有登录；
怀疑凭据泄露时还应退出相关活动登录。列表/写入失败可重试，不伪装成操作成功。

顶部菜单的退出同样等待服务端撤销成功；网络错误时保留页面并提示重试，
不再只清理界面造成“看似退出、服务端登录仍在”的情况。

启动时若显示「暂时无法确认登录」，表示认证服务或网络故障，不等于退出。
当前地址与 Cookie 保留，账户页面不会加载；恢复后点「重新尝试」重新核对登录。
无需因为临时故障清浏览器数据或重复注册。

退出登录不会修改密码、退出第三方身份提供方或阻止之后用有效凭据重新登录。
怀疑密码泄露时还应修改密码，怀疑 API 密钥泄露时应单独撤销该密钥。
本地密码修改须输入当前密码并确认新密码；成功后全部旧控制台登录立即失效，
包括当前浏览器，需要使用新密码登录。已连接的网络设备与 API 密钥不受影响。
发现异常登录请先撤销会话，再修改密码；怀疑服务密钥泄露时还须单独撤销该密钥。

没有本地密码的第三方账号不能在这里创建密码，请通过原身份提供方管理凭据。
当前 Web 控制台尚未接入邮箱验证、密码找回或 2FA，不能用未验证的联系邮箱
找回账户。实现边界与接口规则以
[服务端账户说明](https://github.com/xunara-net/xunara-server/blob/main/README.md#账户自助管理)
及 [ADR 索引](../../adr/README.md) 为准。正式部署必须启用 HTTPS。
