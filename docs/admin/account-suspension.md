# 禁用与解禁账号

进入平台后台「用户管理」，按用户、租户或状态筛选，找到账号后点击「禁用」或
「解禁」。在确认弹窗填写管理原因，再确认提交；不要输入密码、令牌等秘密。

## 禁用会发生什么

- 账号不能通过密码、第三方或通行密钥重新登录；原有浏览器登录全部撤销。
- 该账号委托的 API 权限暂停，但不自动撤销独立 API Key。
- 账号、密码、绑定、通行密钥与历史保留，禁用账号仍占成员额度。
- 已连接设备、设备接入 Key、DNS、ACL、套餐和独立中继**不会被停用**。
  这是账号控制，不是冻结整个网络。
- 用户中心成员页显示只读「已禁用」，不展示平台操作原因。修改成员角色不会解禁。

## 解禁与保护

解禁后需要重新登录，已撤销的浏览器会话不会恢复。未撤销、未过期的 API Key
可再次使用，永久停止自动化应另外撤销 key。

不能禁用最后一位启用的所有者，不能把已禁用所有者当作可登录的恢复入口。
先安排另一位可登录的所有者再操作；删除 / 降权也遵守同一保护。

账号被其他操作改动时，旧页面不能覆盖。失败或冲突会保留原因并暂停再次提交；
点击「刷新核对账号」查看最新事实，再确认原操作。若状态已经达到，不反向执行。
旧服务端缺少状态 / 版本时显示未知并禁用按钮，需要先升级服务端。

该切片尚不提供邮件通知、密码找回、完整注销、网络冻结或独立超管人身份。
