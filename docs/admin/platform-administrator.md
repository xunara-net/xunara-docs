# 平台添加用户与管理员通行密钥

## 添加用户

在“用户管理”点击“添加用户”，明确选择已有网络，填写用户名、资料、角色和初始密码。
账户遵守该网络套餐的成员额度；Free 的已有 owner 已占唯一成员名额时需要先调整套餐。
这不是开通新网络，网络 owner/admin/member 也不是超级管理员。
通过可靠渠道交付初始密码，并请用户及时更改；平台不能读取已有密码。
提交超时或结果未知时先关闭弹窗、刷新列表核对，不要直接重复创建。

## 管理员登录与绑定

1. 从可信 HTTPS 管理入口使用平台管理令牌首次登录。
2. 从侧栏或管理员头像菜单打开“管理员安全”，绑定手机、电脑或硬件安全密钥，给每把密钥取便于识别的名称。
3. 后续使用登录页“使用通行密钥登录”；可以为同一管理员绑定多把。
4. 解绑会撤销所有管理员 Passkey 会话。使用剩余凭据或恢复令牌重新登录；
   没有配置恢复令牌时不能解绑最后一把。

浏览器仅保存四小时的短期会话，不保存首次输入的永久恢复令牌。
凭据写入需十五分钟内登录；失败或超时需核对列表后重新验证，系统不自动重试。
租户通行密钥不能登录平台后台；解绑平台密钥不会影响租户账户、组网设备或中继。
当前只有单一部署运营者身份，不是多管理员 RBAC 或 TOTP 两步验证。
