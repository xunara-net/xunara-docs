# 超管直接重置随机密码

入口是独立平台后台「用户管理」，不是普通用户中心。只有平台授权能重置，
租户 owner/admin、服务 API Key 和匿名不具备此权限。

## 操作顺序

1. 通过可靠独立渠道核实账号持有人，不仅凭未经验证的联系邮箱。
2. 核对所属网络、登录名、启用状态和本地密码能力，点击「重置密码」。
3. 填写管理原因，勾选已核实身份；不在原因中输入密码、令牌或证件资料。
4. 确认后**立即替换密码并退出该账号所有控制台登录**，不再生成重置码。
5. 复制本次弹窗的随机临时密码，通过已核实渠道交付，告知所属网络的正常登录页。
6. 用户登录后必须设置自己的新密码，再重新登录。关闭弹窗清除明文，交付后清理剪贴板。

管理员不能查询旧密码或重新读取临时密码；列表只有「待本人修改」状态。
关闭后丢失临时密码可重新核实并再次重置，之前的临时密码立即失效。
仅已有本地密码且账号启用、网络允许密码登录时可重置，不能为第三方专用账号新增密码。
取消确认不写入；用户的最终密码由本人设置，不应交付给管理员。

## 结果与故障

版本冲突、超时或服务故障不能被当作确定未提交。页面不会自动重试；
先「刷新核对账号」，重新核实身份，再明确确认立即重置的影响。
刷新不取回明文，不自动生成第二个密码。

临时密码登录只允许本人改密和退出，第三方 / Passkey 新登录同样不能绕过；
这是后端强制约束，不只是隐藏菜单。密码、限制、原会话撤销、旧码作废与审计
原子提交，失败不允许部分更改。

组网设备、设备接入 Key、中继、API Key、第三方及 Passkey 绑定不删除，
其他账号 / 网络不受影响。此功能不等于完整账户接管恢复，疑似泄漏须单独核查其他凭据。

旧重置码入口已停用；无需给用户发送码或引导其到兑换表单。
用户步骤见[忘记密码](../user/password-recovery.md)，接口 / identity v19 /
成套备份与回退以[服务端手册](https://github.com/xunara-net/xunara-server/blob/main/docs/password-recovery.md)
和 [ADR-0042](https://github.com/xunara-net/xunara-server/blob/main/docs/adr/ADR-0042-platform-random-password-reset.md)为准。
