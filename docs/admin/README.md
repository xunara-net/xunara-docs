# 超管手册

超管后台是**独立前端与独立入口**（`/admin/`），使用平台令牌登录，不复用用户控制台的
会话与路由（规范 §43、§94）。

## 登录

- 平台令牌来自服务端环境变量 `XUNARA_PLATFORM_ADMIN_TOKEN`（只监听内网/白名单）。
- 后台使用 `sessionStorage + Authorization: Bearer`，不发 Cookie，因此没有 CSRF 面；
  401/403 立即清空本地令牌。
- Break Glass 账号用于灾难恢复，使用必须告警并事后复核（补充规范 §87–§89）。

## 功能（规范 §44–§50）

| 页面 | 能力 |
|---|---|
| 总览 | 用户/活跃/Tailnet/在线设备、套餐分布、DERP 状态、系统健康 |
| 用户 | 查看、禁用/解禁、重置密码、改套餐、改设备额度、查看设备/Tailnet、强制下线、删除 |
| 租户 | 组织列表、租户详情、跨租户用户管理、配额 |
| 套餐 | 套餐编辑器：名称、价格、周期、设备数、成员数、CIDR/Exit Node/Subnet Router/API/ACL/审计等能力位 |
| 网络池 | 网段池、分配与冲突检查 |
| 中继 | 中继审批、可见性、限速、区域/分组、成本与调度 |
| 审计 | 全量审计查询、按 actor/action/target 过滤、导出 |
| 系统 | 版本、组件健康、功能开关、平台 API 状态 |

## 套餐编辑

套餐是数据：新增套餐**不需要**改程序。编辑器保存后立即对新用户生效；已有租户的
套餐变更写入审计。

## 操作纪律

- 任何跨租户操作为高敏操作：先确认目标租户与影响面，操作后核对审计。
- 删除账号保留"最后账号 / 最后 owner"保护，后台应显示拒绝原因而不是静默失败。
- 平台令牌泄露等同全平台失陷：发现泄露立即轮换并检查审计。
