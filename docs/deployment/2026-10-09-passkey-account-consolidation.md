本记录对应服务端
[`8eba882`](https://github.com/xunara-net/xunara-server/commit/8eba882)
和用户控制台
[`1fb9539`](https://github.com/xunara-net/xunara-web/commit/1fb9539)。
接口、配置与字段以
[服务端账户接口迁移说明](https://github.com/xunara-net/xunara-server/blob/main/README.md#account-api-migration)

## 本轮实现与清理

- 独立 Web 的登录页和安全中心接入通行密钥，支持添加名称、列表、使用时间、
  删除、取消认证器交互及失败重试。
- 删除服务端旧通行密钥管理模板、创建脚本、业务处理器和重复会话撤销逻辑；
  删除 Web 不再使用的旧会话接口、类型及转换器。
- 公开旧地址保留带弃用提示的薄兼容适配，复用同一账户事务与权限检查，
  不继续维护第二套业务实现。旧通行密钥管理页面跳转到独立 Web 安全中心。
  必需的客户端浏览器授权页面、HTML 登录以及尚未完成 Web 功能对等的其他模块
  不为“清理”直接删除；最终移除遵守规格规定的渐进迁移流程。
- 关键源码增加中文注释，解释 Human/Machine/Service、租户边界、单次挑战、
  Cookie 绑定、事务审计、撤销失败和兼容适配的保留理由，不保留注释掉的旧代码。
- 顶部菜单与安全中心共用账户撤销 API。密码或通行密钥登录后的设备授权、
  SSH 检查及旧控制台回跳使用完整导航，不再误入 SPA 的兜底页面。

## 自动化与本地浏览器

- 服务端 `go build ./...`、`go vet ./...`、`go test ./... -count=1`、
  `go test -race ./... -count=1` 全部通过。
- 前端 70 项 Vitest 测试、`vue-tsc` 类型检查及 Vite 生产构建通过。
- 自动化覆盖成员权限、服务密钥拒绝、CSRF、跨用户及跨租户隔离、挑战重放、
  浏览器绑定、列表读取故障、凭据与审计事务回滚、已撤销发起会话拒绝，以及
  多数据库连接上的注册与撤销竞争。凭据删除后不能凭旧验证结果签发新登录。
- Chromium 的 CTAP2 虚拟认证器在 localhost 安全上下文中实际完成注册、登录、
  使用时间更新及删除。守护进程重启后凭据和当前登录仍可用；删除后的凭据
  无法再登录。取消分支通过注入浏览器 `NotAllowedError` 验证，未宣称测试
  实体认证器的指纹、面容或手机同步。授权回跳的本地检查使用模拟 HTML 页面。
- 列表和删除失败可重试；退出写请求失败保留有效页面及服务端登录。
  桌面与 390px 页面无整体横向溢出，浏览器无 JavaScript 页面错误。

## 公网调试部署

在已授权的调试机上，先校验当前版本，再停止控制面并备份一致状态；
二进制与静态入口原子替换，新静态资源先于入口发布。回滚快照保存在
`/root/xunara-rollback/20261009T073610Z-passkeys`，受 root 目录权限保护。
原有组织配置、服务单元、网段、套餐和中继证书指纹未改，升级未修改数据库迁移。

实际验收结果：

- 升级前创建的浏览器登录在新版本仍有效，租户、Free 的 10 台设备额度与
  自动分配网段保持。控制面、中继和 nginx 均正常，健康检查通过。
- 公网仍为 HTTP，服务端未启用通行密钥；新安全中心明确解释 HTTPS、固定域名
  与租户 WebAuthn 配置要求，不展示可用的新增按钮。匿名账户读取拒绝，
  无 CSRF 的写入拒绝；旧管理页面的重定向与弃用提示正常。
- 在浏览器注入列表和退出写入失败时，界面明确报错，不伪造空列表或成功退出；
  恢复请求后可刷新、退出，已退出登录不能再读取账户通行密钥。
- 官方 Linux 客户端 1.104.1 生成真实设备授权地址；未登录浏览器进入独立 Web
  密码登录，再完整回到后端审批页面。人类登录成功尚不能接入网络，显式批准
  后设备才连接；另一台客户端用文件传递的预认证密钥接入。
- 两台官方客户端在强制 DERP 模式下完成加密网络内的 HTTP 数据传输。
  首次冷启动探测超时，重试后通过；再次退出控制台登录后，设备地址和连接
  保持，传输继续成功。未改变客户端协议或设备审批语义。
- 调试租户随后通过平台管理接口归档；原有 `default`、`team` 组织及其数据保留。
  测试端的临时密码、Cookie、预认证密钥及客户端状态清理，不进入仓库或日志。

## 未覆盖与后续

本轮不是完整产品验收：公网 HTTPS、实体及跨平台认证器、Windows/macOS/移动端
客户端兼容矩阵、直连和中继故障转移仍须独立验证。通行密钥不等于 TOTP/2FA；
邮箱验证、密码找回、完整登录审计与其他内嵌模块的功能对等迁移仍是后续工作。
当前 HTTP 入口只用于调试，不应存放生产账户口令。
