## 边界

多池是三层地址管理，不是 VLAN；默认池自动分配，附加池需在设备详情显式改 IP。
不同池的权限隔离必须通过已有 ACL/Grants 配置。删除池、套餐降级保留旧设备 IP
与历史租户预留，不向其他租户释放仍可能使用的地址。

Linux 命令默认检查本地网络，冲突/读取失败就停止，不静默改 DNS 或路由。
不支持服务端替官方客户端自动重写 Quad100，不保证识别未配置本地路由的外部软件源，
也不表示 Windows、macOS、Android、iOS 已有同等自动检测。

共享网页不替代独立官方客户端需要的租户 DNS/受信证书；网页路径不能当作
login-server。
